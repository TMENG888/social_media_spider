# 小红书：帖子与作者双阶段

默认启动流程：Redis帖子队列 → 全局完成门禁 → MySQL作者去重 → Redis作者队列 → 作者统计回填。

## 第一阶段：帖子

保留原331项检索任务ID、顺序、任务池、租约和本地断点，不自动重置异常任务。
专题一采帖子，不采评论；专题二采帖子和评论讨论串。项目名称和分类NULL保持原规则。
帖子阶段不再访问作者主页，只保存详情内的作者ID、名字和主页链接。粉丝数、作者获赞数留空。
帖子、评论、持久化ASR任务由现有断点库保存；帖子结果和ASR意图同一SQLite事务写入，waiting_import状态避免抢在基础帖入库前处理。入库成功后启动ASR；入库失败任务仍保留，恢复时先导入已有帖再补字幕。small模型没有改变。
每个关键词进入搜索结果时只选择并确认一次最新排序。正常关闭详情后沿用该排序，不重复打开筛选控件；仅当搜索上下文确实丢失、必须重载搜索地址时才重新确认一次。没有改变年度边界、单篇网页死信、验证码停机等保护。

## 第二阶段：作者

只有原帖子池total等于清单数量，completed等于total，且pending/leased/failed都为0，才开放作者队列。
作者阶段每次处理下一位作者前也复查门禁。如果帖子任务被重新开放，作者阶段停止。
这里“完成”是帖子任务的服务端完成状态，不代表平台不可访问的死信已经补齐。死信仍是采集缺口。

源数据为MySQL的ods_social_media_post（平台=小红书），按24位作者ID去重。跨专题同作者只领取一次。
现有CSV只作审计依据，不上传覆盖数据库。审计：1709帖、731评论讨论串、1362作者，601帖两项作者统计为空。
实际发布作者数量以阶段启动时的数据库为准。无效作者ID会阻止发布并输出诊断，不静默忽略。
作者任务池为原帖子campaign加后缀-authors-v1；任务ID=hash(xhs-author-v1:作者ID)。
payload不含动态主页token或关联帖子数量，反复发布及源数据增长不会导致任务冲突。
所有节点平等领取作者任务；任务仍有租约、心跳、有限重试。帖子和作者进度分开显示。

作者阶段复用本机同一个浏览器页签和登录会话，逐一打开数据表保存的目标作者主页。
只读取可见统计，不访问未公开接口，不自动处理验证码。首次作者访问限制就停止本节点。
“作者点赞数”对应平台显示的“获赞与收藏”合计，不拆成纯点赞数。无法识别不伪造为0。
默认每位作者间隔8–15秒，每8位作者休息45–90秒；帖子同样每8篇休息45–90秒。休息期间可响应安全停止。沿用45–60分钟运行、30–60分钟休息机制；这些设置用于降低持续负载，不保证不会触发平台限制。

## 持久化与回填

采集作者 → 本地authors.sqlite保存pending_import快照 → MySQL租约校验+事务回填 → 本地completed → Redis确认。
回填只UPDATE平台=小红书且作者ID相同的全部帖子的作者粉丝数、作者点赞数；其他字段和评论表不变。
更新与原帖子/ASR导入共用数据库锁。旧帖子导入已有行时，只在原作者统计为NULL时补值，不能覆盖作者阶段结果。
SQL失败、入库后确认失败或重启时，可从本机快照恢复；UPDATE是幂等的。其他节点领取时也可安全重采并回填。
快照在worker/.state/authors/{postCampaign}/authors.sqlite；结果在worker/runs/authors/{postCampaign}/。
每个campaign作者快照只采一次。后续增量周期如需刷新已完成作者，应另建版本/周期，不自动删除历史状态。

## 启动与迁移

五台worker默认Phase=auto：先帖子，再作者。
需要只运行帖子时：powershell -File .\run-worker.ps1 -Phase posts
需要进入作者模块时：powershell -File .\run-worker.ps1 -Phase authors
authors模式同样受全局门禁约束，不能跳过未完成帖子；只支持Redis+MySQL，不支持导出模式回填。
local或ExportOnly只执行帖子导出，不发布生产作者任务。
所有活动节点必须安全停止后更新同一版本再重新启动；旧进程不会热加载改动。不要混跑旧版作者内联采集。
保留worker/tasks、.state、runs、浏览器会话和凭据；不要删除这些目录。

## 本次验证边界

9项受控测试覆盖帖子/ASR意图原子保存及恢复、门禁、去重、正确零值、SQL字段范围、租约失效回滚、先持久化后确认、SQL失败恢复及安全验证停机。
3项真实Redis隔离队列测试覆盖全局门禁、多机器无重复领取、租约拒绝及安全归还；测试记录已清理，生产任务未改。
真实页面测试：两个专题各1帖，帖子阶段作者页面跳转数均为0；最新排序/搜索上下文保留。另采1位作者，粉丝2、获赞与收藏11。
补测有评论样本“海淀内城稀缺洋房 保利熙瑞”：成功保存1帖和1条评论讨论串，作者页跳转数仍为0。
浏览器测试关闭ASR运行和MySQL写入；ASR模型并未在本轮重新转写验证，真实数据库回填尚未进行（仅SQL模拟/故障注入）。
既有Redis异常任务未重置，生产作者阶段尚未开放；还需要所有帖子任务完成后使用真实数据库凭据运行闭环。
