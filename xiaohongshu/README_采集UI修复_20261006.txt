本机 common 目录已更新，五个 worker 共用这些生产模块。
其他机器不会自动获得本机代码，需要安全停止后安装同日 UI 修复更新包。
当前验证状态：专题一两篇及作者回退恢复已通过；专题二一篇后遇到真实安全验证并停止。
尚未发布最终更新 ZIP、尚未重置 Redis；需人工完成安全验证后再复测专题二。

修复内容：
1. 只读取真实可见的最新排序控件，排除 aria-hidden 和极低透明度的重复控件。
2. 点击后面板被卸载时重新打开并读取当前 DOM，不再等待失效的旧定位器。
3. 兼容嵌套筛选面板和鼠标悬停展开，确认后关闭面板。
4. 帖子关闭优先使用真实关闭按钮和遮罩空白区域，不连续浏览器回退。
5. 已自行返回搜索页视为关闭成功；同页兜底恢复搜索地址后重新核验最新排序。
6. 作者入口仅在当前帖子弹层内定位，取消强制点击后方搜索卡片。
   若一次作者回退落到首页，恢复原关键词搜索页、重新确认最新，再从结果列表点击原帖。
   仅有限四轮定位原帖，不直接导航详情地址，找不到则停止并保留断点。
7. 搜索上下文、排序、浏览器或连续失败阈值异常时停止本节点，避免连续消耗后续任务。
8. 保留原始安全限制、登录、租约异常，停止后不再继续导航。
9. 非视频帖子不再等待不存在的 video 节点。
10. 批量重置工具在首次写入前验证全部任务，避免缺失任务导致半批重置。
11. 安全停止日志截取实际警告附近文字，不再只显示页面页脚。

不改变：专题检索词和 Redis 任务 ID、年度日期条件、八篇非今年停止窗口、分类为空、
专题一不采评论/专题二采评论、MySQL 幂等入库、后台 ASR 队列和凭据储存方式。

测试证据和重置审计保存在本次工作目录，不放入生产 worker 中。
