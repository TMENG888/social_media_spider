# 知乎采集源码（隔离测试阶段）

同步本机当前 Playwright/Redis/MySQL 程序；仅有源码、安装入口和配置模板，没有 worker、生产任务、登录态或凭据。

当前业务代码针对专题二四个项目的检索，采回答和专栏文章，核验原始创建时间、最新排序及可见正文，保留 SQLite 断点和评论进度。遇到登录、验证码、访问限制或 403/429 停止，需人工处理；不绕过权限或自动处理验证。

## 准备

在 `common` 执行 `npm ci`，将 `config.example.json` 复制为 `config.json`，准备自己的 `tasks/redis-tasks.json`、各节点目录和 Redis 配置。具体读取字段及 CLI 参数见 `common/src/worker.mjs`、`queue.mjs` 和 `run-worker.ps1`。MySQL 示例默认 `127.0.0.1`，必须显式配置自己的合法目标；密码通过进程环境/隐藏输入提供。

新数据、输出、浏览器下载默认在 E 盘，安装目录可通过安装脚本的真实参数指定。源码仓库不包含浏览器和便携运行时。

## 验证边界

现有本机实网记录仅确认人工登录后的搜索可访问，后续详情访问仍遇到平台限制，尚未得到完整正文/评论实网验收。不能把代码、隔离 DOM 或队列测试通过视作知乎年度任务已采集完成。仓库内飞书监控原有的平台支持范围也不会因为新增此目录自动扩展。
