## 当前流程与边界

- 2026-10-21修正：专题二新任务使用04目录的 `topic2_pipeline_v107.py`，v106兼容入口也改为原本地FP32 RoBERTa。复用切片/标签及评论优先项目归属，完成切片后只按本片正文评分，不调用Qwen打情绪数字，不继承源文章分。旧来源分仅留档；旧v96/v105批次和Excel不自动重算。本轮重算Qwen10条、Codex5条样本，详见04目录说明。

- 两专题批量入口是 `run_bulk_v96.ps1`，已接入v97品牌组/经营主体/项目身份补全；少样本与历史补标入口 `run_single_unit_v93.ps1`、v94/v95等一起保留。以公共工程README的“当前入口”为准，不以历史版本编号猜入口。
- 发布者角色现有的是少样本/全文评估程序，不是已完成的全库数据库自动回写服务。其Codex参考和复核脚本是特定样本的评审记录生成代码，不能用于自动产生新的人工金标准。
- 广告数据库程序的授权范围是北京臻澐项目口碑、仅空值“是否广告”；原少样本程序支持广告/非广告/待判断，数据库程序是是/否。两种口径不能混用。
- 本次只复制代码、说明、配置、字典和代码自带固定测试样例；不复制全量源数据、交付结果、日志、缓存、检查点、依赖安装目录、虚拟环境、环境变量文件、密钥或数据库密码。

## 使用前必读

这是当前机器上的代码归档，不是已经完成跨机器部署的安装包。原源码为字节一致副本，里面的输入、输出、网关、解释器、外部依赖等绝对路径仍保留；复制目录不意味着所有入口都已改为相对路径。尤其不要直接运行旧的prepare或reference脚本覆盖冻结评估数据。

广告程序还依赖原小红书worker的mysql2和连接函数；广告少样本程序引用原专题核心路径。发布者角色与少样本导出使用原任务D盘输出。原目录均保留，所以这些依赖没有因本次整理失效。相应详情见每类说明。

API Key只通过环境变量配置（Qwen：`YS_LLM_API_KEY`，Luna专用代理：`LUNA_API_KEY`）。数据库密码通过隐藏输入或当前进程环境变量传入。不得把密钥写进此目录或提交版本库。

Python依赖见公共工程requirements.txt；Node导出使用Codex已有的artifact-tool运行环境，广告数据库程序另依赖mysql2。本次未安装新依赖，未发起API请求，未执行数据库查询或写入。

`整理清单_20261014.json`记录每个副本的原路径、目标路径、大小与SHA256；`整理核验_20261014.json`记录复制与语法核验结果。需要维护时先选定05中的公共核心为本目录的维护版本，避免同时改动原目录和副本。
