# 当前专题一 Qwen 流程与批次恢复源码

- `semantic-r49`：当前 `topic1_semantic_pipeline.py`、全字典候选/逐项裁决、最短充分证据、对象身份、摘要证据以及完整结构回归；`production_snapshot` 为该冻结版本实际依赖的 Python 源码快照。它与早期共用工程有重复模块，不可随意混用版本。
- `batch500`：本机 500 篇运行器、有界格式修复、住宅范围保护、热度基线读取及导出入口。它是专门批次程序，不是可对任意数据直接运行的通用批处理服务。

仅备份程序，不包含原始工作簿、documents/results、收费 calls、审计结果、生产 scope_control、输入参考集或 frozen_version.json。`version_contract` 的原版冻结/语义验收保护保留，不因发布源码而绕过；在新环境直接运行原批次入口会因缺输入/批准清单而停止，这是预期保护。示例策略不代表已获授权，也不证明新批次符合业务验收。

原批次文件的恢复必须使用获批原数据及其哈希，不能拿发布适配后源码的哈希冒充原冻结版本。需要运行新批次时，应先明确新输入、输出目录、项目/字典、API 配置和验收授权，再单独生成对应版本合同。某些诊断/导出工具保留原批次路径和固定数量约束，执行前逐一核对。

`test_contracts.py`、`batch500/test_recovery.py`、`batch500/test_scope_recovery.py` 为本次选择的离线合约回归；不运行任何 API 驱动的实验入口，不触发 300/500 篇实际重标。
