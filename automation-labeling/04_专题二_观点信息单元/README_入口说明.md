### 2026-10-21：打标明细改为每个原切片一行

标准导出已接入 `topic2_slice_rows_v109.mjs`：同一来源、相同起止位置的切片合并为一行，不因涉及多个项目或多个标签重复输出。相同文字来自不同来源、或在同源不同位置出现，不互相合并；同原切片ID对应不同范围，或同片原文、数值评分、热度等不一致时拒绝合并，不取第一条掩盖冲突。

多项目列按对应顺序并列；标签按“项目ID＋字典ID”去重，并在标签JSON内保留项目归属。`项目与标签证据`保存各原项目视图、摘要、理由和证据，不将甲项目标签广播给乙项目。内部项目视图、标签来源关系和指标仍按原口径计算，合并仅发生在最终“打标明细”，不覆盖已成功缓存。

本改动不调用模型，也不重新裁决Qwen旧有表达或情绪；项目间类别差异在合并行和原视图证据中保留，不擅自选一个项目的态度当整片结论。Codex Skill的整体情绪单选属于独立标注规则，不代表该历史Qwen缓存已完成该项语义复核。需要重新计算项目指标时使用内部项目视图，不能将合并行的多值project_id直接送入旧单项目聚合器。

`topic2_pipeline_v107.py` 已接入原本地情感模型：原切片与打标 → 评论项目归属 → 当前来源全部切片完成 → 逐片本地RoBERTa评分 → 按新分汇总导出。原成功标签、摘要、项目裁决及旧缓存保留。`topic2_pipeline_v106.py` 兼容入口也已改用同一原模型，不再调用Qwen数值评分。

- **评分输入**：仅当前切片正文；评论按“父评论＋全部子评论”整体评分。不传父文章、旧分、标签和项目元数据，昵称从模型输入中剥离。
- **评分模型**：沿用2026-10-14评论回填程序的 `uer/roberta-base-finetuned-jd-binary-chinese`，固定revision `133367c1beb2d5b04e6df3e7ec218a49575bc437`，本地ONNX FP32推理。此次已找到原源码及模型文件，不是Qwen评分，也没有添加未经核实的情绪字典。
- **原计算公式**：每条发言的softmax正向概率在文本段内平均，再对切片中全部发言等权平均，乘100并保留两位小数。普通切片是一条发言；父子评论按原程序分发言推理后仍合成一个评论分数，不拆开打标签或增加来源数。超过510 token的发言沿用原首/中/尾三段方法，每段最多510 token，极长文本可能未覆盖全文；分段位置和覆盖情况留档。
- **分数含义**：这是京东评论二分类模型的正向输出，不是满意度，也没有独立中性类别。不会强制咨询类为50，也不由Qwen修改分数；原模型对咨询、反讽可能不准确。改为当前正文输入，不意味着模型判断已全面改善。
- **调用和恢复**：本地CPU推理不调用情绪API、不耗模型Token。批内输入去重复用；模型文件、词表、版本及正文绑定缓存。失败保留成功标签，只补未完成评分，绝不使用旧分或默认50兜底。原Qwen评分代码和缓存只保留历史，不作为当前入口。
- **汇总**：切片明细用本片新分；同来源命中同标签的不同切片先求均值，再按来源求标签均值。重复项目视图不重复计权。来源表显示全部切片均分，旧来源分只供追溯；热度、覆盖率和数据量口径不变。
- **不要求旧分存在**：新数据用 `aggregate` 汇总，不能继续用旧版“CSV必须有情绪分”的汇总校验。历史已导出的结构可用 `prepare_export` 定向换分。

### 2026-10-21：热度空值自动补算

当前v106／v107／v108的`aggregate`、`prepare_export`及标准`export_workbook`已接入`topic2_heat_v110.py`；Codex Skill重建指标也调用同一实现。不重跑切片、标签或情绪模型，只补热度空值，已有值（包括0）保留。

默认只读本机`C:/Users/YS-Insight/Desktop/专题数据/ods_social_media_post_01.csv`、`ods_social_media_post_02.csv`完整快照。新导出的两专题全量快照可通过`aggregate(..., heat_baseline_files=[全量文件1, 全量文件2])`指定；缓存payload也可保存`heat_baseline_files`供导出使用。不是实时数据库查询，不写源CSV、数据库和成功模型缓存，不用当前5／10／1000条标注样本建立排名。只有发生缺失时才加载基准；文件缺失或父文与快照互动值冲突则报错，不悄悄使用别的基准。

公式严格沿用`../../热度_互动指标计算.sql`：两专题全部文章共同按平台＋内容类型分组，点赞／收藏或推荐／分享／评论权重0.27／0.27／0.26／0.20。逐项P99.5线性插值截尾、log1p、平均秩÷该项有效数，按可用权重归一后乘100保留两位小数；单项至少5个有效值、非恒定且最大值大于0，每文至少2项可用。空白、展示文字不可当0；无法算的保留空并在内部`heat_backfill_audit`记录原因。

每个父文章ODS主键只算一次，文章切片与关联评论共用其热度；来源、切片、热度文章来源和议题中位数同步更新。审计包含公式版本、基准文件哈希与文件时间、各组计数、保留／补算／仍缺失结果。只补缺，不重新校准历史非空分数，因此不宣称新旧热度基准完全一致；不自动重跑或覆盖已交付历史Excel，不补互动深度指数。
