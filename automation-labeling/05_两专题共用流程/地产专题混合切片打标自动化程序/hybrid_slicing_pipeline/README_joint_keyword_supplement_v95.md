# 切片与已有标签联合补标

生产入口 `run_single_unit_v93.ps1` 已接入。全文语义切片 → 单片分组模型打标与查漏 → 真实定义及证据核验 → 联合关键词补标 → 两张Excel交付。评论不拆，关键词不决定切片边界。

每片遍历专题一323、专题二580条适用字典标签。从真实标签路径及强调方向拆出核心对象和属性，检查“本片原文＋本轮开始时的标签明细”。只读取标签层级词和强调方向，不读取ID、编号或JSON字段名作为事实。保存初始标签快照，新补标签不能继续补出下一标签，重复执行不增加相同标签或说明。

例：原文“会所设茶室。还配备游泳池”，已有“会所功能·茶室”标签可帮助找会所泳池候选，但要追溯茶室标签的原文对象证据。对象与泳池事实连续、没有空间或发言者切换时，可直接补入“会所功能·游泳池”。如果原文实际是“体育公园设泳池”，不能借旧标签里的“会所”补成会所泳池。只有标签文字出现某属性、原文未出现时，明确记录为不补标，而不是新增事实。

原文明确“每间卧室都配有观景飘窗”，且已有高置信、有定位证据的主卧或次卧标签，可以在这一全称卧室范围内补相应窗标签。部分卧室不等于每间卧室；不能用全称说法推算主卧数量，跨句数值仍要复核测量对象与口径。新增标签都按原字典回填八键JSON，片内同ID只保留一次。历史明确否决不能被关键词无理由覆盖。

“标签补选与纠错”页增加联合字眼来源、来源标签ID、来源标签原文证据及对象绑定方式；“补选覆盖记录”页增加联合遍历、补入、待核及不补入数量。字眼位置区分切片文本和来源标签文本；正式属性和对象证据使用全文原始字符位置。项目、摘要、切片、评论文章映射及指数不改。只处理当前主表，未自动恢复待核或排除单元；不能保证零漏标。
