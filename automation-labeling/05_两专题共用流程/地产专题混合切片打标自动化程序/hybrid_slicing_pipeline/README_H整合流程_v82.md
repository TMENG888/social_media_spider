# H整合切片打标流程

入口为 `run_delivery_v82.ps1`。旧入口和历史交付未覆盖，可保留作为回退对照。

## 实际处理顺序

1. 按种子20261008抽取两专题80篇文章，找到专题二30个有评论父文章的全部可唯一关联评论。按文章内容、视频文本、已有图片OCR的顺序选择首个非空主体，不混合拼接。
2. 标签字典分组，各组都阅读全文和本组全部定义。分组不是关键词截断。模型找有据标签和原文位置，提出切片建议。
3. Reduce阅读全文和各组建议，统一决定连续语义边界。同一对象连续的做法、参数和解释尽量放一起；不同项目/户型的同标签允许分别出现。评论保留整条，不按标签拆行。
4. 原核心逐片核对定义、对象、证据和文案，生成一片多标签单元。项目身份、评论父文章和指数继承沿用原核心的审计协议。
5. D核对Map已找到、但最终片中未确认的标签，送模型逐项盲审。新增标签需有同对象的原文依据，不能直接复制旧版答案。没有进入交付片的Map提议另列审计，不能静默消失；落在排除区间的提议不直接认定为漏标。
6. H对九类已知风险标签再次复核：业态、科技系统、面宽、户型面积、毛坯/精装单价及总价、装标口径。词面规则只提出疑点，不作否决依据。中文数字、口语单位和数值倒置由模型按证据解释。
7. 不支持、意见冲突、低置信度或API失败的标签不计入确认标签明细，但其候选ID、证据和原因留在追溯与备注，相关行进入人工审核。原文和切片不删除。已撤回标签的旧肯定理由移到审计，避免与最终标签矛盾。
8. Hscope按专题分别传研究边界，再核对全部已选标签、研究相关性、文案/说明数值和项目归属。专题一全国，不套用北京及专题二候选项目限制。疑似无关只标审核、不删行；标签确定不支持时转待核候选，保留审计。不把待出让地块推测当确定项目。专题二只有模型建议有明确字典项目别名引文、置信度至少0.95时才提出上下文回填，仍标需人工确认。此阶段不重切正文，也不承诺找到所有漏标。
9. Hreview保留Hflex主表，将Hscope的全标签、项目、文案建议附到追溯和人工审核，不直接覆盖。真实测试发现Hscope仍误撤有据的噪音标签，因此不晋升为自动改写默认。整批尚无完整人工金标准验收，均标需人工审核。
10. 校验标签八键与字典精确一致、原文定位、评论完整性、父文章关联、长ID和指数继承，导出Excel与CSV/JSON。

## 三个同批方案

| 方案 | 确认条件 | 主要风险 |
| --- | --- | --- |
| Hflex | 看全文辅助确认对象；属性证据仍必须在当前片 | 模型仍可能借错前文对象，需独立验收 |
| Hlocal | 只看当前片核验 | 切片未重复项目/对象名时，可能误拒正确标签 |
| Hconsensus | 两路同时支持才确认；分歧进人工队列 | 更保守，可能留下更多正确但待核的标签 |

三种方案共用原核心切片和D输出，两路模型复核结果共享，因此不是每种方案都重做整篇文章。方案之间的标签数量差异不是准确率排名。Hfull失败实验曾将全国范围误套北京，9篇专题一受影响、4篇整篇误删，已退回，失败JSON保留。Hscope修正边界并禁止凭一次范围判断删行，但仍误撤至少一条有据0157噪音标签。默认导出Hreview非破坏性审核底稿：Hflex字段保留，末轮变更只作建议；不宣称全面胜过D或原MapReduce。

## 运行

在本机安全配置 `YS_LLM_API_KEY` 后运行，密钥不进入程序文件、提示词、日志或Excel。

```powershell
.\run_delivery_v82.ps1 -OutputDir .\test_results_v82_new -DeliveryRoute Hreview -ExcelPath 'C:\明确交付目录\两专题测试交付.xlsx'
```

全部网络生成、核验、补标、重试共用当前阶段的并发上限10；核心阶段完成后才启动后处理，不能同时另开一个API测试程序。超时120秒，瞬时错误最多重试2次，认证失败停止。成功请求和来源有检查点，恢复不重复计费调用成功缓存。

若代码、字典或源数据变化，会生成新签名，旧请求缓存仅在请求完全相同时复用。不要把之前版本结果改名冒充新结果。Excel创建用配套工具；导出后会重新读取核对值，并产出预览用于视觉检查。

## 验收边界

本轮设有26处生成前独立核验的真实事实锚点，以及7个独立构造句式挑战。参考答案不传给生成阶段；它们不是完整人工金标准，不能由其通过率推导全量准确率。

H九类风险复核不是全部VOC的第二次全量召回。Hscope只复核已选标签与争议候选，不替代全字典Map召回，仍可能漏掉从未被提出的标签。项目建议、研究范围、其他标签、摘要和做法仍需人工核验。自动通过仅表示机器检查通过。

本轮初次句式测试5/7精确符合预期：中文面积被错误正则提示诱导，层高错借案例返回待核而非明确否定。代码已将规则否定提示替换成中性证据检查，允许中文数字及单位，另做同例回归；两轮结果都保留，不能删去失败案例。本轮上游H对照保留原提示的实际结果，新提示不冒充已在全部真实来源重跑。

修正提示后同7例真实API回归7/7符合预期。这仅证明该次七个构造案例，不能推出真实文章全量准确率。20261010实际批次：80篇文章、113条评论全部进入处理，其中1篇原文边界协议失败保留审核；导出122产品、277文章观点、82评论观点，31条评论在原核心排除或没有有效单元。主表655个标签、19条产品做法待补、82条观点摘要待补，481行均需人工审核。已确认仍存在大平层误标大高、明湖印材料漏标、雄安推测项目及熙瑞上下文归属待核，不可以直接用于正式统计。

无标签单元不等于漏标：原文可能无关、证据不足或字典没有对应标签。缺失指数保留空值，真实0保留0。按文章统计热度时按源文章去重，不能累加多个切片及评论重复继承的指数。

费用分两种口径：每个方案的必要逻辑请求费用，以及本轮所有对照策略共享后的实际请求费用。原核心、补标复核、句式测试分别列出；usage或超出已配置价格档时，报告未知而不是计为真实0。
