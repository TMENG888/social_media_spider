# 全文一次切片与标签方向回填 v5

运行 `run_delivery_v5.ps1`。默认全局并发10，模型qwen3.7-flash，地址http://127.0.0.1:3000；密钥来自YS_LLM_API_KEY或隐藏输入，不保存。

每篇文章一次逻辑API调用，输入完整主体和专题全部适用标签方向、打标说明；模型同时输出语义片段、多标签、产品做法或观点摘要。程序精确匹配标签强调方向，回填最新VOC字典的ID、编号和五级路径。没有关键词候选筛选、第二次模型补标或独立模型复核。瞬时网络错误仍可能重试。

主体优先顺序：文章内容、文章视频内容、已有图片OCR。专题一30篇；专题二50篇且30篇有评论，处理这些文章的全部已有有效评论。评论不切分，继承父文章指数。v5.1按平台＋文章id唯一关联；交付映射文章id保存评论源表文章id，父文章ODS真实主键单独保留在来源追溯。项目优先评论明确对象，未提及则采用父文唯一明确项目，歧义不强填。

同次模型自检和程序检查均通过、各适用置信度达到0.90才自动通过；这不是实测准确率。未知标签方向、摘要复制、对象冲突及证据不足进入审核。单次调用不能保证完全不漏标，应人工抽查。失败保留检查点，不静默修复或再次计费；重试失败来源需要另行明确处理。

结果CSV/JSON/Excel输出到独立目录，原始数据和历史结果不改。`--prepare-only`只核验抽样和字典；`--smoke-only`测试两篇文章和一条评论；同目录再次运行复用已保存响应并重新做程序检查，不重新生成。启动脚本默认导出Excel，`-SkipExcel`跳过导出。

父文章被明确排除为非专题内容、评论又没有独立地产证据时，将评论移入排除候选和人工审核队列，保留原文和原模型结果。检索词命中不等于正文属于该项目。标签项目对象与补全后项目冲突时清除冲突标签，不能偷偷改成新项目；含反驳的回复串若摘要仅保留单方态度，则进入摘要审核。
