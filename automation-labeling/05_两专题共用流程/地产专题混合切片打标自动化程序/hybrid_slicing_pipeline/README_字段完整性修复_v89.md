# MapReduce/H后置字段完整性流程

不更改原始CSV、历史交付或旧默认入口。`completeness_v89.process`是可复用的后置流程：接收旧核心输出的完整document、rows、traces、calls和Map审计，返回主表、排除审计、未完成待核。新测试用`run_completeness_v89.ps1`。未经业务金标准验收，不将实验性语义裁决强行覆盖旧默认。

## 流程

1. 固定同批来源与语义边界。文章缺标签、理由、摘要/做法或有已知异常才触发补全；评论始终完整一行。历史无单元来源也复查，不丢31条历史排除评论。
2. 补全请求看到完整原文和本专题全部合法路径、强调方向及真实定义。专题二品牌、土地、区位配套不按专题一产品做法边界排除。
3. 标签从真实字典回填八键JSON。`VOC-xxxx`与`Dxxxx`仅唯一编号转换。引文只恢复确定的标点/空白差异，保存精确原文及恢复前文本；不改数字、口径、词义，不模糊猜证据。
4. 超长摘要只定向压缩摘要，不重新判标签。统一定义校验另外检查完整字典漏项，给出`missed_keys`仅作为替代核验候选，不能直接写成有效标签。
5. 只有实际结构、证据、定义或遗漏异常才定向修复一次。替代标签再用同一真实定义核验；不无限加轮数。一条单元失败不能让同请求其他合法单元全部失败。
6. 有据标签、逐标签理由、忠实文案缺一不可进入完整主表。不适用或重复事实有两轮明确支持才移排除审计；字典缺项、不确定、API失败另存未完成待核，不静默删除或填占位。

## 保留边界

未知品牌、经营主体、案名、城市及缺失源指数不能编造。指数缺失保留null，不填零。项目归属仍按原文及候选字典，有疑问须人工核查。没有人工金标准时，机器置信度和主表非空率不是准确率。

全局并发10，API/模型与旧配置一致，所有阶段及重试共用ApiRunner信号量；120秒硬超时、瞬时错误最多2次重试、认证失败停止。密钥只读安全环境变量。成功请求缓存及来源检查点可恢复；修改代码或字典使来源检查点失效，但相同请求仍复用API缓存。

输出两个独立Excel。每个保留主表、源记录、渠道/文章/评论统计、排除审计、人工审核及未完成待核。统计必须同时披露完整主表、排除和待核数，不通过缩小分母声称全批补齐。源文章指数按文章ID去重，不累加切片/评论继承值。

测试状态以本批`smoke_gate.json`、`new_test_status`及实际来源/请求记录为准。正常历史单元未全量重审，不把本轮称为所有单元的全量重新打标或总体漏标率下降证明。
