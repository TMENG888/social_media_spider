# v8 漏标召回与原文证据落地

入口：`run_delivery_v8.ps1`，实现：`delivery_v8.py`。v7保留为上游全字典审核模块，历史v5/v6不作为当前入口。

## 如何解决三类问题

1. 首轮漏标：完整文章输入，专题一323项、专题二580项标签全部分支审核。关键词不限制标签范围。首轮选择、分支支持/歧义和最后综合选择均进入最终候选，不允许因为后续一轮没选就静默消失。
2. 名称回填：模型选择程序颁发的固定字典编号，由程序回填标签ID、编号和五级路径。兼容名称只有唯一匹配才接受；“容积率”等重名词不能任选。
3. 程序误删：取消一刀切的相邻句对象限制。修复含“建面167㎡”和“宽厅8.5米”同句时误删客厅尺寸的问题。整套面积不能代替房间尺寸、私人茶室不能代替会所茶室等硬反例仍保留。

## 独立证据核验

文章另做全文专题范围核验，防止考试、影视、餐饮或极度错乱ASR因为撞关键词进入交付。只有模型高置信度且排除引文确实存在时才移出正式单元，原文与排除理由继续追溯；关联评论仍检查自身是否有明确地产/项目内容，不盲删带明确项目证据的评论。

最终核验只输入完整主体与候选标签定义，去掉标题、关键词及父文章事实，防止背景事实泄漏到本切片。每项标签返回支持/不支持/歧义及理由；支持标签提供逐字引文。项目归属仍由唯一父文和项目字典在后续程序中补全，不从父文补评论的配置或情绪。

程序验证引文是否属于所选切片。引用明确且在该切片中唯一存在时，可以修正标签证据编号，但不改变文章语义切片边界。评论始终整条一行，子回复序号不是主体片段编号。多段省略引文只有每段均按顺序逐字存在时才接受；不通过相似度猜原文。

一次完整修复后，仍缺少候选决定时，按少量明确编号独立裁决，避免重复生成全文又丢失其他标签。无法定位的标签保留原模型选择及理由，转为证据歧义待人工审核，不计为已解决的漏标，更不默默删除。协议失败仍记录为未完成，不能冒充零问题。

“已有宽泛关注标签覆盖”不能作为删掉具体道路、设施标签的理由；定义中的“或”不要求所有条件同时满足，示例不变成新增必填条件。发生协议残留或JSON截断时，增加一次有输出上限的精简协议修复；再失败明确进入人工审核。HTTP每次尝试采用120秒总截止时间，不被网关持续小块响应无限延长。

## 交付与评估

交付仍是一片多标签八键JSON；产品/观点字段顺序、评论平台文章ID关联、父文章ODS主键追溯、指数继承及空值/零值区分保持。

`evaluate_delivery_v8.py` 检查已知证据的漏标、错标及局部房间尺寸反例，同时输出逐来源版本对比。标签数增加不代表正确率提高；空标签也不能全部算漏标。模型置信度、协议完整、已知锚点通过均不能证明全量零漏标。正式统计仍应由人工建立独立金标准，并处理审核队列。

费用按API usage分阶段估算，只使用已知输入≤32K价格档。超档、缺usage不填零，估算不代替网关账单。重试和失败语义输出也可能收费，保留调用历史。

## 2026-10-09 切片内标签覆盖补强

最终证据审核后，对全部候选（含被否定的标签）执行有界、分批的逐单元核查。被错误否定的候选不能失去补标机会。
模型返回每个标签在各现有切片中的 placements；程序仅接受可逐字、唯一定位的引用。
同标签在不同独立对象切片内可重复出现，同切片内多个同标签事实合并为一个标签。
不能因一处引用错误丢弃其他有效引用，不能因补核响应遗漏原有正确落点而直接删除。
项目预售总面积不能作为套内户型面积，拒绝理由保存在审计且触发人工审核。
该阶段不改变切片边界；多户型合并问题仍需单独的全文语义边界复核。
全文边界复核由模型选择对象起点，程序只回填连续终点；不是关键词决定切片。标签随后重新落到各独立对象。
产品做法增加截取原文检查及独立证据校验，例如中西双厨不能擅自写成两个独立房间。修正和原先问题保留审计。
已知证据锚点失败时启动脚本会报错停止验收，不再仅打印失败而返回成功。
定向真实 API 回归结果：`test_results_v8_targeted_recovery_20261009_api/targeted_recovery_report.json`。

## 证据上下文与回填验收

合法证据区间保留对象上下文，不为缩短展示引文而压缩语义证据。
例如“臻澐的会所”之后的“茶室、棋牌室、25米恒温泳池”，可在同一连续会所介绍内匹配相应设施标签；不能把短引文没有重复“会所”误判为证据不足。
直接引文用于简洁展示，完整区间保存在来源审计。仅在模型编号无效或越界时，按唯一逐字引文修复编号。
中文数量与户型简写可支持数量属性，但不能推导未说明的面积、房间归属或效果。
启动脚本增加逐标签精确字典回填核验；标签ID、编号、五级路径及强调方向不一致时停止验收。
当前集成样本回归：80篇文章、120条评论、214个单元、39个已知证据检查通过、511个标签精确回填通过。
123项离线测试通过不代表全量语义准确率；78个无有效标签单元、12个空产品做法、11个空观点摘要及7个证据待复核标签仍保留审核记录。
