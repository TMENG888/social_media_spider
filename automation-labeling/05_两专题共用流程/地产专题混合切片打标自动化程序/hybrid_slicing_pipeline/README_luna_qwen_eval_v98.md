# Luna 独立参考标注与 Qwen 配对评估

用户指定代理：`https://in.aquria.cn:13003/v1`，指定模型：`gpt-6-luna`。
只读取独立的 `LUNA_API_KEY`，不读取或转发 `YS_LLM_API_KEY`。

## 当前实现状态

`luna_review_gateway_v98.py` 已实现隔离调用适配层。最新要求严格串行，拒绝 concurrency≠1；不同实例共享单路闸门，本机不同适配器进程以系统文件锁防重入。离线测试不能证明真实代理兼容性或标签质量。
当前尚未检测到专用密钥，只有不带凭据的 `/models` 连通检查（401），没有发送真实原文到代理，没有实测标签质量。
代理是否支持 Responses、Chat、严格JSON schema、reasoning参数及是否原样转发模型，须先做合成内容兼容性测试，不能拿官方接口支持当成此代理已经支持。
默认批量入口尚未切换，也没有为改变模型重跑已有成功来源。

## 两种配对对照

1. 同切片标签对照：Luna只看冻结原文、切片、完整相关VOC字典和业务字段口径，不看Qwen标签。独立完成对象、标签、摘要和精确原文证据后再匹配Qwen结果，定位标签误标、漏标、重复、证据错位及摘要幻觉。
2. 全文端到端对照：Luna只看冻结全文、标题和评论父文关系，独立切片与打标，再按原文区间、语义信息点、实际对象和标签匹配Qwen结果。没有这一步，Qwen漏掉整个信息点会从验收分母中消失。

评论整条保持一行，父文身份和评论话题关系分开取证。VOC-0377继续采用会所内部健身房即可打健身房器械的新定义，其他定义不放宽。
不把长上下文能力当全字典精确召回的证明；按完整业务分支拆批，保留每个分支审查覆盖和被排除信息。

## 参考标准分层

- Luna原始输出：机器候选参考，不是人工金标准。
- 通过原文位置、字典、对象关联和独立证据复核的参考：机器审核参考集。
- 人工确认的完整来源标签及信息点：人工金标准。Codex确认与人工确认分别记录，不改写来源属性。

初次Luna独立标注不能看到Qwen预测。分歧仲裁时匿名化模型身份和随机交换呈现顺序，可能判Qwen正确而Luna错误，也可能判双方都错；双方一致不自动判真。
Luna失败不能由Qwen兜底并伪装成Luna参考。用于生产的新打标任务优先Luna，必要时显式回退Qwen；每条结果必须记录实际路由和回退原因。该生产路由需在兼容性和小样质量验收后接入默认入口。

## 指标及分母

沿用已有少样本反馈指标体系：处理完整率、标签完成率、重复标签率、切片近重复率、标签精确率、完整来源信息/标签召回率、证据可追溯率、证据语义支持率、摘要忠实率、待审核率及平均/总耗时和成本。
对Luna未经人工校准的参考，只报告“相对机器审核参考”的TP/FP/FN及一致性，不能直接声称人工精确率。
召回率必须有全源独立参考与完整未打出信息点，不能仅审核Qwen已经产出的标签。
文章与评论、专题、平台、单项目/多项目、否定/数字/指代/字典边界及错误类型分组。
冻结开发样本和保留评估样本，按父文章组隔离，禁止把调参用过的样例继续当独立验收集。
本轮从以前的产品、观点两交付单元各选10条疑难记录，共20条。既有14来源工程样本不替代这20条。冻结旧unit_id、原文范围、完整来源与父文、字典签名、抽样理由和旧预测。Qwen按原自动化完整流程在独立测试目录重跑选中来源，按原文范围匹配疑难单元，明确切片边界变化；Luna不看旧预测，独立给出保守候选；Codex逐条对照原文和字典裁决，保留双方正确、双方错误及不确定结果。这里只能评价有意抽取的疑难小样，不能推断全量准确率。

## 代理安全与成本记录

强制1路，不允许2路，20条顺序处理；初始每次HTTP开始间隔至少5秒。每次尝试有120秒绝对截止，最多4次总尝试。系统锁拒绝第二个本机适配器进程同时调用，退出后自动释放锁，不依赖删标记文件。
408/409/429/5xx和网络故障使用指数退避与抖动。401/403立即停止，其他4xx不重复轰炸；过长Retry-After直接返回待恢复，不缩短服务端要求。
成功结果按地址、模型、提示词、数据、schema和阶段签名缓存。失败历史保留，每次尝试usage单列；HTTP诊断日志不再次加计费用。
用户报告代理不收费，记录为用户报告的现金支出0；这不证明底层服务无成本，也不把缺失usage当0。Luna不能套用Qwen价格计算。
不打印密钥、Authorization、原始服务端错误正文或内部推理输出。
