## v4.5 全文切片（2026-10-09）

文章选定主体全文一次输入模型，不再按1800字分窗口；API模式不再发送规则预切片建议。无损句段编号只用于模型选取原文证据位置，不代表最终切片。最终边界由模型按对象、户型与共同主题确定，同一户型的连续配置介绍不因换句、换段、标签变化或长度被硬拆。取消600字的硬拆/验收限制，但独立语义验收仍检查是否混入不同对象或无关事实。

模型生成和独立验收均看到完整主体；评论仍保持整条一行，父文章全文只作归属背景，不作为评论证据。提示词要求全文检查总述与详述的重复事实、切片重叠和无理由碎化，不按相同标签一刀切删除不同户型/不同房间的数据。输出Token上限32768；输出被截断或接口拒绝超长输入时保留失败审计与已知usage，不悄悄截取正文或退回分窗口。一次全文生成仍可能触发独立验收、定向修复和覆盖补标，不代表每篇仅一个HTTP请求。

版本和请求签名已更新，旧分窗口检查点不会被本版当作已完成结果。建议新结果使用独立输出目录；历史Excel及源CSV不修改。全文请求的模型质量尚需真实API样本与人工核验，离线回归仅验证程序合同。Offline模式仍是明确的规则候选测试，不冒充模型全文切片。

## 调用与验收

原网关http://127.0.0.1:3000，qwen3.7-flash，默认全局并发10。生成/验收/重试共用Semaphore。每请求超时120秒，瞬时错误最多重试2次；401/403停止剩余请求。使用标准库HTTP客户端，无需为新版安装requests。

正反少样本是教学数据，不能进入真实交付。模型生成后独立调用语义验收。所有适用生成与验收置信度、标签置信度均>=0.90且程序检查无问题才自动通过；其余需人工审核，具体原因在备注。自动通过仅表示机器验收，不证明真实准确率。

v4.4先把选定主体无损编号为句段。模型选择source_start_id/source_end_id作为语义切片连续区间、evidence_start_id/evidence_end_id作为标签证据区间，程序按端点取回连续原文，不要求模型抄写长原文；未知或非法区间拒收。评论只有一个完整句段，不能用局部编号拆开。转写文案、数字、定义与对象仍需独立语义验收。第一次结构/证据检查失败最多做一次定向修复，不放宽验收门槛。

独立验收发现原文支持且字典合法的遗漏时，进行一次覆盖补标，再做语义验收；无原文证据、硬约束不符或字典外的建议不自动采纳。仍有遗漏或争议进入人工审核。无据项目ID、非法品牌、无法支持的经营主体不当成事实交付，原始模型建议留在审计记录。排除及API失败保留全原文和所属文章关联，未完成来源也进入人工审核队列。

按请求内容、模型、字典/提示词和原始证据签名保存成功请求，复跑不会重复支付已成功调用；语义验收失败可继续使用已保存生成。按文档检查点恢复。变更输入/规则会产生新签名。调用记录不保存密钥。费用按usage估算，与真实网关账单分开；未知usage/超32K档未知费用单列。
