# 相邻语义合并（实验功能）

默认保持原MapReduce入口delivery_v76.py。本轮同批24篇文章、36条评论测试未证实收益，因此没有默认启用合并。

原启动命令不变；仅显式增加-EnableSemanticMerge才启用delivery_v77.py。实验入口逐来源执行原MapReduce之后，增加相邻语义合并。所有请求共享原ApiRunner的并发10限制。评论不合并，跨原文间隙不合并，不同项目身份冲突不合并，不因标签相同直接合并。

模型初判、组文案及独立验收须均有据；失败保持原行。既有标签八键字典值不改写、不新增标签，原文证据连续保留，原单元ID和完整追溯保存在合并审计中。人工审核状态不因合并升级为自动通过。

只测试新增阶段可运行run_merge_comparison_v77.py --baseline 原版delivery_results.json --output-dir 独立目录。依赖YS_LLM_API_KEY本机安全配置，不要把密钥写进命令或文件。

详细测试与回退结论见交付目录“相邻切片合并测试与回退说明.md”。本功能不是项目归属修复或漏标补标功能，旧版已知缺陷仍需单独处理。
