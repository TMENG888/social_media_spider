- common/src/douyin-data.mjs：公开浏览器响应映射、单列分帧 JSON、最新排序实际请求核验、响应体超时、帖子/评论/作者字段；文章内容 NULL、标题去话题、标签英文逗号分隔；帖子及评论按小红书同口径清洗，清洗标注固定五项 JSON，保存清洗原文审计。

- common/src/collector.mjs：2026 年度核验、断点恢复、专题二评论、基础文章入库、后台 ASR 及独立回填；评论清洗审计持久化，异常页面及控件诊断留存。
- common/src/run-worker.mjs：生产 Redis 调度、帖子/作者阶段、独立样本测试、数据库回读。
- common/src/author-phase.mjs、common/src/login-browser.mjs
- common/src/checkpoint.mjs：文章与 ASR 意图原子持久化；补采评论时保留已有字幕；正在运行的 ASR 不被重新入队覆盖。
- common/src/import-mysql.mjs、common/src/lease-guard.mjs：表结构兼容、幂等入库、分类 NULL、有效字幕保护、死锁有限重试、租约校验、共享锁限时可停止等待；旧断点入库时也规范标题/正文/标签。
- common/src/asr.mjs、common/src/asr-jobs.mjs、common/src/asr-worker.py、common/src/text-cleaner.mjs：small 模型、媒体持久化、后台识别、质量检查与精准重试/死信。

- common/src/redis-connection.mjs、common/src/redis-dispatcher.mjs、common/src/redis-task-queue.mjs、common/src/redis-task-manifest.mjs、common/src/redis-auth-check.mjs

## 验收限制

实际验收进度见“验收状态.md”。完成媒体识别不等于字幕逐字准确；歌词、低置信度或质量拒绝样本需要复核。评论“分页耗尽”仅说明当前账号可见的公开评论已返回结束证据，不承诺平台统计值中的隐藏/删除评论也可取得。年度边界规则也不能证明平台搜索绝无遗漏。

## 年度闭环实测追加修改

- common/src/redis-task-queue.mjs：限定任务 ID 的原子领取及任务结果只读查询，继续保留原租约校验。
- common/src/redis-dispatcher.mjs：按指定关键词顺序领取；第一个任务不完整时不推进第二个任务。
- common/src/run-worker.mjs：`--only-keywords` 年度模式，与十条抽样测试互斥。
- common/src/run-worker.mjs：`--verification-sample 20` 限定关键词的真实 Redis 闭环抽样；样本成功后安全归还生产任务，不误标年度完成。
- common/src/collector.mjs：保存年度终止窗口的八个帖子 ID/日期证据。
- common/src/douyin-browser.mjs：年度实测中修复目标单列播放器未激活、误用弹层背后的卡片及评论滚轮向搜索页串联问题；目标居中激活、可见弹层优先、仅滚动当前评论面板。评论面板缺失时保留部分评论并停止，不把其他帖子的评论当作当前帖子数据。
- common/src/collector.mjs：已知失败候选或未完成评论的候选存在时，拒绝确认年度完成。
- common/src/douyin-browser.mjs：长评论滚动距离/面板高度变化也计为分页进展，避免尚未滚到下一页触发点就误判八轮无增长；失败审计保存主分页结束状态及缺失回复根 ID。
- common/src/douyin-browser.mjs：回复展开控件使用整段文本精确匹配，避免长评论面板被误认为按钮；通用控件异常也附带已观察到的部分评论。
- common/src/douyin-browser.mjs：回复展开及评论关闭属于页内动作，不等待无关的延迟导航；评论面板优先使用自身关闭按钮。单列评论关闭失败时只有确认原关键词搜索地址、非详情弹层及可见结果卡片后才继续，不重载或误按 Escape；平台限制仍停止。
- common/src/douyin-data.mjs：提取真实主评论响应中内嵌的 reply_comment 并保留父评论关联；仅完整内嵌数组数量等于声明回复数时认可结束，部分预览不能冒充完整。
- common/src/douyin-browser.mjs：回复分页同时识别“展开更多”和“展开更多回复”。主分页已结束但回复不完整的断点，校验文章 ID、评论统计值、主分页证据及缺口父评论后，只补缺口回复，按 ID 合并旧记录；任一缺口仍无真实结束证据则不能通过。
- common/src/collector.mjs：收尾关闭错误不能覆盖原始评论/详情错误；验证码或登录异常不再尝试收尾点击。
- common/src/collector.mjs：记录抽样帖子 ID；抽样只验收选中范围，年度模式仍拒绝任何已知缺口。评论补采失败时合并原断点及本轮部分评论，不以空数组覆盖已保全内容。
- common/src/import-mysql.mjs：在原共享入库锁内按最多 250 个业务 ID 批量查询既有主键，再按主键更新；避免每条评论重复扫描业务字段，保留幂等和租约校验，发现重复业务行时拒绝任意覆盖。不修改数据库结构。
- common/config.json：年度帖子上限明确为 0（不限条数）。

启动器和最终核验脚本位于 Codex 工作目录，不放入生产 worker。年度实测未结束前不得将生产池目标任务标为完成。
