# 抖音分布式采集

采集范围固定为 2026 年。专题一 223 项，专题二 56 项，共 279 项。专题二仅保留北京臻澐、建发海晏、中海·安澜北京、保利熙瑞及既有明确别名；专题二采集评论。分类字段始终为 SQL NULL，项目字段分别为“全国地产设计产品力监测”和“北京臻澐项目口碑”。

## 使用

将整个“抖音”文件夹复制到每台 Windows x64 机器。每台选择不同的 worker-01 至 worker-05；只启动两台也可领取所有任务，不能在两台机器上使用相同的 worker 编号。不要复制其他机器的 `.state`、登录资料或 Windows 加密密码文件。

1. 双击对应 worker 的“环境预检.bat”。Node、浏览器、Python、small ASR 模型均随包携带。
2. 首次双击“保存Redis密码.bat”，隐藏输入 Redis 密码。保存前验证账号；DPAPI 仅适用于保存时的 Windows 机器和用户。
3. 首次双击“登录抖音.bat”，在浏览器中人工登录后回到终端按 Enter 保存登录状态，再双击“启动采集.bat”，隐藏输入 MySQL 密码，数据库账号默认 social_user。不自动填写验证码，不绕过平台限制。
4. 使用“安全停止当前任务.bat”停止当前操作并取消后续自动重启。当前正在处理的入库或 ASR 操作先收尾，未完成任务和本地断点保留。

每轮 45–60 分钟，正常限时停止后休息 30–60 分钟继续。访问限制、登录失效、上下文异常或 Redis 租约失效会停止该节点，不自动连续尝试后续关键词。休息不能保证不触发平台限制。

## 采集机制

检索开始时选择“单列”，悬停“筛选”选择“最新发布”，发布时间不限，再按帖子真实 create_time 核验年度。不会每篇帖子重选排序。单列卡片按当前 DOM 的 data-e2e-vid 重新扫描、点击，关闭弹层后保留原搜索页；帖子阶段不访问作者。

连续八篇可核验为 2026 年之前的帖子才触发年度边界。未知日期、页面异常、无增长不能冒充年度完成。平台搜索本身并非全量数据库，此规则无法证明平台所有帖子绝无遗漏。

专题二通过正常页面交互读取评论分页及回复；有评论但未取得分页结束证据时报告未完成并保留部分数据，不以零评论确认成功。

抖音“文章内容”保持 SQL NULL，不重复存放视频配文；“文章标题”去除 #话题，“文章标签”去重后以英文逗号连接。标题/配文和评论使用与小红书相同的清洗工具，删除表情、控制/零宽字符、压缩空白和连续重复字符；“清洗标注”保存原始文字数、清理后文字数、表情个数、其他字符个数、重复字符个数五项统计 JSON。话题剥离属于字段拆分，不计入删除字符数，文章统计针对去话题后的配文/标题。原文及评论回复关系保留在本地审计文件，ASR 字幕清洗统计另存 ASR 审计；不混入文章标题统计。重复入库保留原始统计，不重新归零。

文章基础数据与 ASR 意图原子持久化到 SQLite。基础数据先入库，small/CPU/int8_float32 后台解析真实媒体并单独回填“文章视频内容”；失败保留精准重试任务及质量记录，不将失败或待处理解释为“无口播”。图文帖不会把配乐当作文章视频口播。

全部全局帖子任务完成后，作者阶段按 sec_uid 去重采集粉丝和获赞数，回填文章。作者阶段和帖子阶段均采用 Redis 租约及独立任务池，旧租约持有者禁止确认或入库。

Redis 地址在 common/redis-config.json 中；出于当前 ACL 兼容性，抖音使用 `xhs:douyin:{douyin-...}` 独立命名空间，不会领取小红书关键词。配置中无密码。两平台共用现有 MySQL 主键分配锁，按平台、项目、帖子 ID 幂等入库。

共享主键分配锁每次等待不超过 10 秒、累计最多 10 分钟，其间检查安全停止和租约；只等待数据库，不重复访问平台。ASR 回填按唯一文章主键单行更新，MySQL 死锁回滚后最多重试三次，不重试平台访问限制。

## 结果和日志

本地断点在 worker/.state/tasks，CSV/JSONL 和状态在 worker/runs。Redis 保存任务状态、租约、领取节点、重试及异常摘要，当前不是完整的远程机器监控或集中日志服务。

不要在采集过程中删除 `.state` 或 Redis 任务，不要把测试状态覆盖生产断点。两关键词前十条测试使用独立 live-worker，不确认生产任务。最新实测验收状态见“验收状态.md”。

## 年度闭环验证

2026-10-09 开始追加不设帖子条数上限的年度实测：使用真实抖音生产池，限定领取“中海 住宅”，只有该词年度完成并确认后才领取“北京臻澐”。限定关键词模式 `--only-keywords` 只改变本次节点的领取范围，不重置任务、重排全池或抢占其他节点的租约。未限定时生产节点仍平等领取全池任务。

年度任务必须记录八篇连续、独立且已核验为 2026 年之前的日期证据；没有增长但未到年度边界则是未完成，不冒充“已采全”。45–60 分钟到时安全归还，休息 30–60 分钟再恢复。测试进行中不能沿用前十条的抽样通过结论声称年度验证通过。
